# جلب دفعة صفحات من ويكي مصدر العربية

هذا الأمر امتداد لميزة جلب صفحة واحدة في فرع `feat/wikisource-text-ingestion`، ويجب دمج تلك الميزة أولًا قبل تشغيل دفعات الصفحات.

## ملف الدفعة

أنشئ ملف JSON مثل:

```json
{
  "pages": [
    { "url": "https://ar.wikisource.org/wiki/صفة_جزيرة_العرب/الجزء_الأول" },
    { "url": "https://ar.wikisource.org/wiki/عنوان_صفحة_أخرى" }
  ]
}
```

## التشغيل

```sh
npm run db:fetch-wikisource-batch -- --file ./wikisource-pages.json --workspace-id YOUR_EXISTING_WORKSPACE_ID
```

- الحد الأقصى 25 صفحة في الدفعة.
- تُفحص الروابط كلها وتُرفض الروابط خارج ويكي مصدر العربية أو المكررة قبل بدء الجلب.
- تُجلب الصفحات بالتتابع، لا بالتوازي، لتقليل الضغط على الخدمة وعزل نتائج كل صفحة.
- يطبع الأمر تقريرًا لكل صفحة؛ إذا فشلت صفحة، يستمر في بقية الدفعة وينتهي برمز خطأ.
- قد تنجح بعض الصفحات وتفشل أخرى؛ أعد تشغيل الصفحات الفاشلة فقط بعد مراجعة التقرير.
- النتائج نصوص صفحات ويب ومقاطع غير مراجعة. لا تثبت اكتمال كتاب أو طبعة مطبوعة أو صحة نسب، ولا تُنشئ كيانات قبلية أو دعاوى تاريخية.
