# استيراد دفعات المصادر والمقاطع

هذا الأمر يضيف مسار إدخال قابلًا للتكرار للنصوص المنقولة يدويًا أو المستخرجة بأداة مرخّصة. لا يجلب صفحات الإنترنت تلقائيًا، ولا يدّعي أنه قرأ كتابًا كاملًا، ولا ينشئ قبائل أو أنسابًا أو ادعاءات تاريخية.

## ملف JSON

```json
{
  "sources": [
    {
      "title": "عنوان المصدر",
      "author": "المؤلف",
      "publisher": "الناشر أو المستودع",
      "publicationYear": 1884,
      "edition": "بيانات الطبعة إن عُرفت",
      "url": "https://example.org/source",
      "accessNote": "حالة الإتاحة وحقوق الاستخدام وما لم يتم التحقق منه",
      "passages": [
        {
          "pageLabel": "الجزء/الصفحة/عنوان القسم",
          "text": "النص المنقول حرفيًا من المصدر",
          "locator": "https://example.org/source#section"
        }
      ]
    }
  ]
}
```

## التشغيل

```sh
npm run db:import-source-batch -- --file ./source-batch.json --workspace-id YOUR_EXISTING_WORKSPACE_ID
```

يلزم معرّف مساحة عمل موجود لتسجيل سجل التدقيق. يجب أن تكون المقاطع قد جُمعت بطريقة تسمح باستخدامها، وأن يحفظ الملف النص الحرفي والموضع المتاح. يقبل كل تشغيل حتى 50 مصدرًا و500 مقطع لكل مصدر.

## قواعد السلامة والصدق

- لا تُقبل إلا روابط HTTP/HTTPS، وتُرفض الروابط التي تحتوي بيانات دخول مضمّنة.
- لا ينشئ الأمر سجلات `TribalEntity` أو `HistoricalClaim` ولا يستنتج نسبًا من تشابه الأسماء أو ورودها في فقرة واحدة.
- المقاطع الجديدة تُحفظ `reviewedByHuman=false`، ويظل وصول المصدر وحقوقه غير محسومين حتى مراجعتها. لا يغيّر استيراد المقاطع حالة `extractionStatus` إلى `EXTRACTED`؛ إدخال مقتطفات لا يعني اكتمال استخراج الكتاب.
- يزيل التكرار باستخدام المصدر ووسم الموضع والنص الحرفي؛ لا يدمج الأسماء المتشابهة.
- يطبع تقريرًا بعدد المصادر الجديدة والمعاد استخدامها، والمقاطع المعالجة والمضافة والمكررة، والأخطاء.
- هذا إدخال نصوص وأدلة، وليس بعدُ محرك استخراج أسماء قبائل متعدد المصادر. يجب بناء استخراج المرشحين واختباره كمرحلة منفصلة، مع ربط كل مرشح باقتباس وموضع ومراجعة بشرية.


## استخراج مرشحي أسماء القبائل من المقاطع

بعد إدخال المقاطع، يمكن تشغيل ماسح الأنماط النصية:

```sh
npm run db:extract-tribal-candidates -- --workspace-id YOUR_EXISTING_WORKSPACE_ID --limit 500
```

يفحص الماسح المقاطع الموجودة في قاعدة البيانات ويبحث فقط عن صيغ ظاهرة مثل «قبيلة X» و«بنو X» و«آل X». ينشئ اقتراحات مراجعة معلّقة مع اقتباس من الجملة الأصلية، ويمنع تكرار الاقتراح نفسه داخل مساحة العمل. قد يفوّت أسماء أو يلتقط ألفاظًا غير قبلية؛ لذلك لا يعتمد أي اسم تلقائيًا ولا ينشئ قبائل أو أنسابًا أو ادعاءات تاريخية. هذه الخطوة لا تجلب الكتب من الإنترنت ولا تستخرج نصوصها.


## جلب نص صفحة من ويكي مصدر العربية

يستطيع الأمر التالي جلب نص صفحة محددة من واجهة MediaWiki API، ثم تقسيم النص إلى مقاطع مع رابط الصفحة الأصلية. لا يقبل إلا نطاق `ar.wikisource.org` عبر HTTPS، ويضع المقاطع في حالة «لم تراجع بشريًا»:

```sh
npm run db:fetch-wikisource -- --url "https://ar.wikisource.org/wiki/صفة_جزيرة_العرب/الجزء_الأول" --workspace-id YOUR_EXISTING_WORKSPACE_ID
```

حدود التشغيل: صفحة واحدة في كل مرة، بحد أقصى 500,000 حرف و250 مقطعًا. الوسوم هي مواضع داخل نص صفحة الويب وليست أرقام صفحات مطبوعة. قد يتضمن النص تنسيقًا أو أخطاء OCR أو نقصًا؛ يجب مطابقة النص مع النسخة المصورة والطبعة قبل استخدامه كدليل. لا يثبت الجلب حقوق إعادة الاستخدام، ولا ينشئ قبائل أو أنسابًا أو ادعاءات تاريخية. يعاد تشغيل الأمر بأمان لتجاوز المقاطع المطابقة تمامًا.
